## 2. Cara Mengganti Foto / Video dengan Berkas Asli

1. Siapkan foto atau video asli dari kamera HP atau fotografer.
2. Ganti nama berkas (rename) agar persis sama dengan nama di tabel di atas:
   - Misalnya: foto pembangunan rumah diberi nama `project-01.jpg`.
3. Salin dan timpa (overwrite) berkas tersebut ke dalam folder:
   - Folder gambar: `assets/images/`
   - Folder video: `assets/videos/`
4. Muat ulang (refresh) halaman website di browser (tekan Ctrl+F5 untuk membersihkan cache).

---

## 3. Tips Optimasi Foto

- Gunakan format JPG atau WebP dengan kualitas 80-85% agar halaman website terbuka dengan sangat cepat di perangkat seluler pelanggan.
- Pastikan pencahayaan foto alami, terang, dan memperlihatkan detail kerapian konstruksi secara nyata.
